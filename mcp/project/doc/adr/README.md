# Architecture Decision Records

One file per decision: `NNNN-short-title.md`.

Rules:

* ADRs are append-only once accepted. To change a decision, add a new ADR and
  mark the old one `Superseded by NNNN`.
* Keep them short: context, decision, alternatives, consequences.
* `doc/reviews/` holds the discussion; the ADR holds the outcome.

Status values: `Proposed`, `Accepted`, `Superseded by NNNN`, `Rejected`.
